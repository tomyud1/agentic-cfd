Agentic CFD progress report · 2026-11-11

Pressure-driven laminar flow between two parallel plates

Verdict of the case: PASS

Goal

The first case of the project. It checks that the workflow and OpenFOAM reproduce a flow whose exact solution is known.

Solved with OpenFOAM by an agent that followed the workflow. gpucfd did not exist yet. It was run later on the same problem, with the same cells across the gap and the outputs formed in the same way.

The problem

  • Water between two very large flat plates, pushed by a constant pressure drop.
  • Slow and steady. The fluid moves in straight layers (laminar flow).
  • Asked for: the velocity profile across the gap, the largest velocity, the flow rate and the friction on the walls.
  • Reference: the exact textbook solution, a parabola.

Results

Verification passed. The simulation reproduces the exact solution: on the finest mesh (128 cells across the gap) the velocity profile differs by \(0.0061\,\%\) of \(u_{\max}\). gpucfd on the same cells gives the same four numbers (largest difference between the tools \(2.7 \times 10^{-9}\,\%\)), its finest run in 0.39 s.

What it means
  • The workflow can take a problem statement to a checked report.
  • Both tools reproduce the exact solution to a tiny fraction of a per cent.
  • The two tools give the same numbers. Across the gap they use the same cells and the same formulas, so they solve the same small set of equations.
  • Neither tool is faster in a way that matters. Every run is over in less than a second.
Limits
  • The tools work differently here. OpenFOAM solves the steady flow directly. gpucfd has no steady solver: it starts from rest and steps in time until the wall friction balances the pressure drop.
  • gpucfd's time step was picked in three timed tries, fixed before the runs. The largest try was the fastest, so a still larger step might be faster.
  • OpenFOAM's times are the first, untuned runs on one core. It was not run again.
  • This is the simplest flow there is. Passing it says little about harder flows.
